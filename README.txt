README.txt - ALT Folder (Assistant Language Teacher)
Last Updated: 2026/05/12
==================================================

1. PURPOSE
----------
This folder contains digital materials, activities, and HTML-based games 
for use by ALTs and possible JTEs in English classes in Japan. 
Content is designed to run locally (no internet required after download) 
and works on standard school computers.

2. FOLDER STRUCTURE
-------------------
ALT/
  ├─ Activities/     → Printable worksheets, flashcards, activities
  ├─ Images/         → Printable pictures, word book vocabulary, etc.
  ├─ Jeopardy/       → Jeopardy Game in HTML and PowerPoint
  ├─ Loteria/Bingo/  → HTML file to create game cards and to draw cards 
  ├─ Tools/          → Files containing content to create worksheets 
  ├─ Typing Game/    → HTML game to practice typing. (Work-In-Progress)
  ├─ Word Book/      → Contains vocabulary from the word book. Can be used for Karuta
  ├─ update.txt      → Log of all changes (adds, removals, modifications) with dates
  └─ README.txt      → This file

3. HOW TO USE
-------------
- Open any .html file in games/ with a web browser (Chrome/Edge/Firefox/Edge).
- Materials and activities are in PDF, .docx, or .txt format – feel free to print or change when downloaded
- No special permissions or server needed. Double-click HTML files to play.

4. UPDATES & CHANGE LOG
-----------------------
- This folder is under active maintenance.
- Every time content is added, removed, or changed, an entry is written to update.txt 
  with the date and a short description of what was modified.
- Check update.txt regularly to see what’s new or removed.

Example update.txt entry (subject to change):
[2026-05-12] ADDED: games/word-match.html
[2026-05-10] REMOVED: activities/old_worksheet.pdf (replaced by new version)
[2026-05-08] UPDATED: materials/verb_flashcards.pptx (fixed typo)

5. TROUBLESHOOTING
------------------
- If an HTML game doesn't load, try another browser or press CTRL+Shift+R.
- Files with Japanese characters in names may cause issues on older Windows PCs – 
  use only English letters, numbers, and underscores in filenames.
- For any missing files, check update.txt to see if they were removed.

6. NOTES FOR ALTs
-----------------
- You may copy individual games, but please keep update.txt together 
  with the folder so version history follows the content.
- If you share the folder with other teachers, remind them to keep the original 
  structure (Activities/, Images/Tools/, etc.).
- I will try to continue to add more content, but it will take time. You are able to adjust the content to your liking.
- In the future, I may add a folder to let people add, but not edit exisiting files. (Planned, but not high priority)
