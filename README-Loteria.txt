1. PURPOSE
----------
The HTML file is used to help create Loteria/Bingo cards. The images folder is added to load the images into the website. Generate-Manifest.exe is used to add or update the list of images into the website automatically rather manually.

2. HOW TO USE
-------------
- Open the .html file in a web browser (Chrome/Edge/Firefox/Edge).
- The images are preloaded into the website.
- The website read folders as titles for the vocabulary.
- Planning to add more? Add a folder and inside the folder add the images for that category.
- Execute the generate-manifest.exe to have a command window run and load the new images into the website.
- Reload or reopen the website, if new images are added.
- "Replace" allows you to select a category to fill the cards. ON the dropdown list, selecting "Append" allows you to add multiple categories to the cards.
- The number of cards allows you to create that amount of cards. Note: Odd number of cards will have one large card alone.
- Press the "Reshuffle" button to reshuffle the images on the cards.
- "Print Cards" is currently selected to view the cards to print. The cards can be printed by pressing CTRL+P or print page. 2 cards fill one A4 Page.
- "Caller Deck" allows you to pull cards from the deck. It is based on the category(ies) selected. Press "Draw" to draw a random card. Press "New Deck" to get a new shuffled deck.
- You can see the "Active" categories and the amount of cards in the deck.

3. TROUBLESHOOTING
------------------
- If an image doesn't load, try another browser or press CTRL+Shift+R.
- If the generate-manifest.exe doesn't work, then open the html in a notepad and manually add the folder and image name.
- For any missing files, please find/update/download them. The file must be in the correct location.
